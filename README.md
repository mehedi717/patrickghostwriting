# Patrick Bermel — Ghostwriter

Marketing website for Patrick Bermel, a professional ghostwriter specializing in memoirs, biographies, business books, and family histories.

**Live site:** https://mehedi717.github.io/patrickghostwriting/

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `process.html` — Process
- `why-hire-a-ghostwriter.html` — Why a Ghostwriter?
- `faq.html` — FAQ
- `contact.html` — Contact

## Stack

Static HTML, CSS, and vanilla JavaScript — no build step or framework. Fonts loaded from Google Fonts (Cormorant Garamond, Inter).

## Structure

- `css/style.css` — site styles
- `js/main.js` — mobile nav, scroll reveals, FAQ accordion, contact form handling
- `images/` — page imagery
